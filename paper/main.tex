\begin{abstract}
We introduce LSSO, a token mixer for bidirectional encoders built around a
learned low-rank linear solve.  Rather than routing values through an explicit
pairwise attention matrix, LSSO constructs an input-dependent relation field
and solves
\[
  (\mu I + \gamma U(X)U(X)^\top)Y = C(X).
\]
This is the left-sided case of a Sylvester equation.  The positive shift makes
the system well posed, while the Woodbury identity reduces the computation to
an $r\times r$ solve.  For fixed relation features, the operator has a bounded
spectral response and minimizes a strongly convex correction energy.
Across retrieval, MS MARCO-to-BEIR transfer, and vision classification, LSSO
matches or approaches attention-based encoders while using substantially fewer
mixer MACs.  Ablations, rank pruning, and sequence-scaling experiments further
show when the global correction is useful and where the current formulation
falls short.
\end{abstract}

\section{Introduction}

Self-attention~\citep{vaswani2017attention} is the standard token mixer in
modern bidirectional encoders.  Given query, key, and value projections, it
computes
\[
  Y_{\mathrm{attn}}=\operatorname{softmax}(QK^\top/\sqrt{d})V,
\]
and lets every token route information from every other token.  That
flexibility comes with quadratic score and value-routing costs.  Most efficient
attention methods reduce the cost by approximating or sparsifying the routing
matrix.  LSSO asks a different question: can a global token interaction be
learned without constructing such a matrix at all?

For an input sequence $X\in\R^{B\times N\times D}$, LSSO learns a low-rank
relation feature $U(X)$ and a content state $C(X)$.  For each head it solves
\[
  (\mu I_N+\gamma U U^\top)Y=C,
  \qquad \mu>0,\quad \gamma\geq 0,
\]
and projects the result back to the model dimension.  Although $UU^\top$ is
positive semidefinite, its entries $u_i^\top u_j$ may be positive or negative.
The system can therefore encode signed token relations while remaining
invertible by construction.

The guiding interpretation is:
\begin{align*}
  \text{LSSO}
  &= \text{isotropic content pass-through}\\
  &\quad - \text{low-rank global correction}.
\end{align*}
Attention learns a row-normalized routing rule; LSSO learns the relation
features of a positive-definite inverse filter.  The two mixers therefore have
different inductive biases even when their input and output shapes match.

The main contributions are:
\begin{enumerate}
  \item We formulate bidirectional token mixing as a learned, positive-shifted
  low-rank solve whose implementation only solves an $r\times r$ system.
  \item We characterize the fixed-$U$ operator through its spectrum,
  conditioning, norm bound, and equivalent convex energy.
  \item We evaluate the mixer on retrieval, zero-shot transfer, vision, rank
  pruning, diagnostics, and long-sequence scaling, including settings where
  LSSO does not outperform attention.
\end{enumerate}

\section{Related Work}

\paragraph{Efficient attention.}
Linformer~\citep{wang2020linformer}, Performer~\citep{choromanski2021rethinking},
Nystr\"omformer~\citep{xiong2021nystromformer}, Longformer~\citep{beltagy2020longformer},
and BigBird~\citep{zaheer2020bigbird} reduce the cost of self-attention
through low-rank projections, kernel approximations, landmark approximations,
or sparse attention patterns.  Despite these differences, they retain
attention as the underlying interaction rule.  LSSO instead replaces that rule
with an input-dependent inverse filter.

\paragraph{Token mixers beyond attention.}
MLP-Mixer~\citep{tolstikhin2021mlp}, gMLP~\citep{liu2021pay}, FNet~\citep{lee2021fnet},
Hyena~\citep{poli2023hyena}, and state-space models such as
Mamba~\citep{gu2023mamba} demonstrate that useful token mixing does not require
dense attention.  LSSO explores a complementary construction: an implicit
low-rank solve designed specifically for non-causal encoders.

\paragraph{Implicit layers and learned solves.}
Deep equilibrium models~\citep{bai2019deep}, implicit layers, graph smoothing,
and regularized least-squares methods place linear or nonlinear solves inside
neural networks.  LSSO is narrower than a general equilibrium layer: it applies
one input-conditioned linear solve with a deliberately constrained
positive-definite matrix.

\section{Method}
\label{sec:method}

\subsection{Encoder Block}

LSSO is used in the token-mixer slot of an encoder block.  In a pre-normalized
Transformer-style block this is simply
\[
  X' = X + \operatorname{LSSO}(\operatorname{LN}(X)),
  \qquad
  X_{\mathrm{out}} = X' + \operatorname{MLP}(\operatorname{LN}(X')).
\]
The replacement is local: the input and output shapes match MHA, so the same
residual path, normalization, positional encoding, feed-forward block, and task
head can be kept.  In the BERT-style retrieval experiments we preserve the
post-LN BERT block used by the baseline; in the ViT-style vision experiments we
use the pre-LN form above.  Thus the comparison changes the mixer, not the
surrounding block convention.

\subsection{LSSO Definition}

For each head, let
\[
  U = XW_u\in\R^{B\times N\times r},\qquad
  C = XW_c\in\R^{B\times N\times d_h}.
\]
There is one pair of scalar solve parameters per head.  We RMS-normalize $U$
along its rank dimension by default,
\[
  U \leftarrow U\big/\sqrt{\operatorname{mean}_r(U^2)+\epsilon},
\]
and solve
\begin{equation}
  (\mu I_N+\gamma UU^\top)Y = C,
  \label{eq:lsso-system}
\end{equation}
where
\[
  \mu=\operatorname{softplus}(\theta_\mu)+\epsilon,
  \qquad
  \gamma=\gamma_{\max}\sigma(\theta_\gamma).
\]
The default experiments use $\gamma_{\max}=0.3$ and
$\theta_\gamma=-4$, which gives an initial $\gamma/\mu$ of roughly
$7.8\times 10^{-3}$ when $\theta_\mu=0$.  More conservative settings such as
$\gamma_{\max}=0.1,\theta_\gamma=-6$ make the global correction nearly vanish
at initialization; in preliminary runs they consistently underused the global
term.

The head outputs are concatenated and projected:
\[
  \operatorname{LSSO}(X)=YW_o.
\]
For padded sequences, invalid tokens are masked by zeroing the corresponding
rows of both $U$ and $C$ before the solve and by zeroing the output at masked
positions.  This mirrors key-padding behavior in bidirectional attention while
preserving the low-rank Woodbury structure over the valid tokens.

\subsection{Woodbury Implementation}

The $N\times N$ matrix in Eq.~\eqref{eq:lsso-system} never needs to be formed or
inverted.  Applying the Woodbury identity~\citep{woodbury1950} gives
\begin{equation}
Y
= \mu^{-1}C
- \mu^{-1}U
\left(I_r+\gamma\mu^{-1}U^\top U\right)^{-1}
\left(\gamma\mu^{-1}U^\top C\right).
\label{eq:woodbury}
\end{equation}
This expression remains valid at $\gamma=0$ and requires only an $r\times r$
solve; Appendix~\ref{app:woodbury} gives the full derivation.
The released implementation fuses the $U$ and $C$ projections into one linear
map for efficiency, but this is algebraically identical to using separate
$W_u$ and $W_c$.  The small positive-definite system is solved by Cholesky in
float32 under fp16/bf16 autocast, then cast back to the activation dtype.  The
current package also provides a custom autograd path whose backward pass reuses
the same Woodbury solve on the adjoint, avoiding a dense $N\times N$ inverse in
both directions.
The core solve terms cost
\[
  O(Nr^2 + Nrd_h + r^3)
\]
per head.  Including projections, the mixer-only MAC formula used in our
tables is
\[
  ND(Hr + D) + ND^2 + HNr^2 + 2NrD + Hr^3.
\]
For MHA we count QKV projections, attention scores, attention-value product,
and output projection:
\[
  4ND^2 + 2N^2D.
\]

\section{Theoretical Properties}
\label{sec:theory}

We first study the linear map induced by a fixed $U$; the input-dependent
operator is evaluated empirically in Section~\ref{sec:experiments}.

\begin{proposition}[Well-posedness]
\label{prop:well-posedness}
Let $A=\mu I_N+\gamma UU^\top$ with $\mu>0$ and $\gamma\geq0$.  Then $A$ is
symmetric positive definite.  Therefore, for any $C$, the system $AY=C$ has a
unique solution.
\end{proposition}

\begin{proof}
For any nonzero $z$,
\[
  z^\top A z
  = \mu\|z\|_2^2+\gamma\|U^\top z\|_2^2
  \geq \mu\|z\|_2^2 > 0.
\]
\end{proof}

\begin{proposition}[Spectral shrinkage]
\label{prop:spectral-shrinkage}
Let $UU^\top=Q\Lambda Q^\top$ be an eigendecomposition over the nonzero
eigen-directions of $UU^\top$, with
$\Lambda=\diag(\lambda_1,\ldots,\lambda_k)$ and $\lambda_i>0$.  Let
$P_\perp=I-QQ^\top$.  Then
\[
  A^{-1}
  = Q\diag\!\left(\frac{1}{\mu+\gamma\lambda_i}\right)Q^\top
    + \mu^{-1}P_\perp .
\]
\end{proposition}

Thus LSSO applies an inverse spectral filter on the span of $U$ and an
isotropic scale on its orthogonal complement.  This gives a more precise view
of the distinction from row-normalized attention.

\begin{proposition}[Bounded fixed-$U$ operator norm]
\label{prop:norm-bound}
For fixed $U$,
\[
  \|\Lsso(C,U)\|_F \leq \mu^{-1}\|C\|_F .
\]
With an output projection,
\[
  \|W_o\Lsso(C,U)\|_F \leq \|W_o\|_2\mu^{-1}\|C\|_F .
\]
\end{proposition}

\begin{proof}
Since $A\succeq\mu I$, $\lambda_{\min}(A)\geq\mu$ and
$\|A^{-1}\|_2\leq\mu^{-1}$.  The Frobenius bound follows from
$Y=A^{-1}C$.
\end{proof}

\begin{proposition}[Conditioning control]
\label{prop:conditioning}
For $A=\mu I+\gamma UU^\top$,
\[
  \kappa_2(A)
  \leq 1+\frac{\gamma}{\mu}\|U\|_2^2 .
\]
\end{proposition}

Propositions~\ref{prop:norm-bound} and~\ref{prop:conditioning} motivate the
diagnostics used in our experiments.  The ratio $\gamma/\mu$ directly scales
the possible condition-number increase; effective rank measures how much of
the rank subspace is used; and correction ratio measures how strongly the
low-rank correction participates in the output.
RMS normalization of $U$ helps control the scale of $U$, although it is not by
itself a dimension-free spectral-norm guarantee.

\begin{theorem}[Energy minimization equivalence]
\label{thm:energy}
For $\mu>0$ and $\gamma\geq0$, the LSSO output is the unique minimizer of
\[
  \mathcal{E}(Y)
  =
  \frac{\mu}{2}\|Y\|_F^2
  + \frac{\gamma}{2}\|U^\top Y\|_F^2
  - \langle C,Y\rangle .
\]
\end{theorem}

\begin{proof}
The Hessian of $\mathcal{E}$ is $\mu I+\gamma UU^\top$, which is positive
definite by Proposition~\ref{prop:well-posedness}.  Setting the gradient to zero gives
$(\mu I+\gamma UU^\top)Y=C$.
\end{proof}

Equivalently, up to an additive constant,
\[
  \mathcal{E}(Y)
  =
  \frac{\mu}{2}\left\|Y-\mu^{-1}C\right\|_F^2
  + \frac{\gamma}{2}\|U^\top Y\|_F^2.
\]
The content projection supplies the local state $\mu^{-1}C$, and the second
term adjusts that state using sequence-wide information.

\begin{proposition}[No-global degeneration]
\label{prop:no-global}
If $\gamma=0$, then
\[
  \Lsso(C,U)=\mu^{-1}C.
\]
No token mixing occurs except for pointwise projections.
\end{proposition}

\section{Experiments}
\label{sec:experiments}

\subsection{Setup}

All main retrieval and vision comparisons use randomly initialized encoders.
The retrieval backbone follows a BERT-style bidirectional encoder
layout~\citep{devlin2019bert}.  We reuse standard tokenization but train every
encoder weight from scratch.  Models are optimized with
AdamW~\citep{loshchilov2019adamw}.
LSSO uses $\gamma_{\max}=0.3$ and $\theta_\gamma=-4$ unless stated otherwise.
Because the feed-forward network is identical across models, tables report
mixer-only MACs and isolate the cost of the component being replaced.

\paragraph{Retrieval protocol.}
The dual encoder has $D=256$, depth 8, 8 heads, and dropout 0.1.  Queries and
documents are truncated to 64 and 512 tokens, respectively, and representations
are obtained by masked mean pooling.  We train with in-batch contrastive
cross-entropy at temperature 0.05, using batch size 64, AdamW with learning
rate $3\times10^{-4}$ and weight decay 0.01, 5\% linear warmup followed by
cosine decay, and gradient clipping at 1.0.  Each target-dataset run uses at
most 50,000 training pairs for 20 epochs; the checkpoint with the highest
validation R@10 is evaluated.  All models see the same sampled pairs and use
the same tokenizer, pooling rule, and three random seeds.

and COVID literature.  Unlike the preceding experiments, this setting does
not allow the encoder to adapt to each evaluation collection.

\subsection{Sequence Scaling}

We benchmark a single mixer layer at sequence lengths from 128 to 2048, using
batch size 8, $D=256$, 8 heads, bf16 autocast, and no optimizer update.
Figure~\ref{fig:scaling} reports forward latency, forward-plus-backward
latency, incremental peak memory, and theoretical mixer MACs.

At $N=2048$, LSSO-r16 uses 0.357G mixer MACs compared with 2.684G for MHA,

benchmark uses an optimized SDPA path related to memory-efficient exact
attention kernels~\citep{dao2022flashattention}.  The practical advantage is
therefore clearest in arithmetic cost and long-sequence latency, rather than
peak memory at every sequence length.

\subsection{Vision and Diffusion Boundary Results}

Table~\ref{tab:cv} reports ViT-style~\citep{dosovitskiy2021image} vision
encoder results on CIFAR-100~\citep{krizhevsky2009cifar} and an ImageNet
subset~\citep{deng2009imagenet}.  The controlled vision runs use
RandAugment~\citep{cubuk2020randaugment}, Mixup~\citep{zhang2018mixup}, and
CutMix~\citep{yun2019cutmix}, following data-efficient vision-transformer
training practice~\citep{touvron2021deit}.  CIFAR-100 uses $32\times32$
images, patch size 2, $D=96$, depth 3, 6 heads, batch size 256, and 100
epochs.  Its augmentation consists of random crop and horizontal flip,
RandAugment, Mixup 0.2, CutMix 0.5, and label smoothing 0.1.  ImageNet-100
uses $224\times224$ images, patch size 8, $D=256$, depth 8, 8 heads, batch
size 256, and 120 epochs, with Mixup 0.8, CutMix 1.0, RandAugment, and label

mixed picture than retrieval: the operator remains competitive, but its

\section{Discussion}
\label{sec:discussion}

The experiments suggest that LSSO is best viewed as a bidirectional global
correction operator, not as a cheaper approximation to softmax attention.
This distinction appears especially useful in retrieval, where an encoder
must compress evidence from the whole sequence into a representation but does
not need causal next-token routing.  A small learned subspace can influence
all tokens through the solve without constructing an all-pairs value-routing
matrix.  This interpretation is supported by the retrieval results in
Table~\ref{tab:retrieval}, the zero-shot transfer results in
Table~\ref{tab:transfer}, and the nonzero correction ratios in
Figure~\ref{fig:diagnostics}.

The same construction is less natural for causal decoding.  Applying a causal
mask breaks the simple low-rank Woodbury form, and an autoregressive extension
would require prefix-restricted solves or a different cached state.  The
diffusion experiment points to a second boundary: global semantic mixing alone
may not recover the fine-grained routing that generation demands.

\section{Limitations}
\label{sec:limitations}

Rank is a genuine capacity choice: some tasks occupy only a compact subspace,
whereas SciFact uses much more of rank 32
(Figure~\ref{fig:diagnostics} and Table~\ref{tab:rank-pruning}).  The vision and
diffusion results are also narrower than the retrieval evidence.  ImageNet-100
has only one seed, and the diffusion study lacks sample-quality metrics.  These
experiments establish useful operating points, not universal superiority over
attention or other efficient mixers.

\section{Conclusion}
\label{sec:conclusion}

LSSO replaces pairwise value routing with a learned low-rank global solve.
The positive shift makes the operator well posed, and Woodbury makes the solve
practical when $r\ll N$ (Eq.~\eqref{eq:woodbury} and
Appendix~\ref{app:woodbury}).  In our experiments this inductive bias is
particularly effective for retrieval: LSSO preserves MHA-level transfer while
substantially reducing mixer computation (Tables~\ref{tab:retrieval}
and~\ref{tab:transfer}).  Vision and diffusion results are less decisive,
which helps delimit the present claim: LSSO is a promising efficient mixer for
bidirectional encoders, rather than a general replacement for attention.

\section{Full Woodbury Derivation}
\label{app:woodbury}

Using the Woodbury identity with $A=\mu I_N$, $C=\gamma I_r$, and
$V=U^\top$ gives
{\small
\[
(\mu I+\gamma UU^\top)^{-1}
= \mu^{-1}I
-\mu^{-1}U(\gamma^{-1}I+\mu^{-1}U^\top U)^{-1}U^\top\mu^{-1}.
\]
}
Multiplying the small inverse by $\gamma$ avoids an explicit $\gamma^{-1}$ and
gives the implementation form
\[
Y=\mu^{-1}C-\mu^{-1}U(I+\gamma\mu^{-1}U^\top U)^{-1}
(\gamma\mu^{-1}U^\top C),
\]
which remains valid at $\gamma=0$.
