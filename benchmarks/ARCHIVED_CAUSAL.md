# Archived causal benchmarks

`benchmark_causal_prefix_lsso.py`, `run_causal_recall_benchmark.py`, and
`run_imdb_causal_lm_compare.py` are retained as historical experiment scripts.
The active project scope is bidirectional encoder mixing with CV as the main
empirical program. Current `LSSO` and `RRLSSO` deliberately reject
`causal=True`, so these scripts are not runnable against the supported API.
