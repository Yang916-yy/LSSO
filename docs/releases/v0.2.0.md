# LSSO 0.2.0 — CUDA backend ABI 1

This release freezes the first public CUDA backend contract for the
trace-normalized LSSO/RRLSSO operators. ABI 1 covers operator schemas, logical
tensor layouts and strides, BF16/FP16-to-FP32 numerical behavior, mask
semantics, rank buckets, and portable fallback behavior.

## Precompiled runtimes

Both runtime wheels target Linux x86-64 and PyTorch 2.11.0. Check the installed
build with:

```bash
python -c "import torch; print(torch.__version__, torch.version.cuda)"
```

| Runtime asset | MathDx | Recommended use |
|---|---:|---|
| `lsso_mathdx_runtime-0.2.0+torch2110cu128-py3-none-linux_x86_64.whl` | 25.12.1 | Default; PyTorch 2.11 + CUDA 12.8 |
| `lsso_mathdx_runtime-0.2.0+torch2110cu130-py3-none-linux_x86_64.whl` | 26.06.0 | PyTorch 2.11 + CUDA 13.0 |

Each wheel contains native code for SM80, SM86, SM87, SM89, SM90, SM100, and
SM120. The loader checks the exact PyTorch version, CUDA version, and backend
ABI before dispatch. Unsupported environments retain the portable PyTorch
implementation; source builds remain available.

## Validation

- 215 repository tests passed.
- 121 native CUDA, Trace normalization, backward, and mask-safety tests passed
  independently under both cu128 and cu130.
- Both installed wheels passed masked RRLSSO forward/backward smoke tests and
  exercised the fused Trace, adjoint, dual-statistics, and radial-grad paths.
- Release ELF files have no build-host RUNPATH and depend on only their matching
  CUDA runtime major version.
- Runtime wheels include the LSSO and NVIDIA MathDx license texts.

Use `SHA256SUMS` to verify downloaded assets.
