# LSSO 0.3.0 - CUDA backend ABI 2

This release freezes the unbounded-alpha Trace solve interface. ABI 2 adds the
compact forward state needed by the fused backward and passes log-alpha into
the Trace kernel, where the solve is evaluated through the stable reciprocal
Woodbury system.

## Operator changes

- The public solve strength is now positive and unbounded:
  `alpha = exp(theta_alpha)`, with stable reciprocal
  `beta = exp(-theta_alpha)` used by Woodbury.
- Trace normalization is the maintained basis contract. Token RMS and the
  bounded `(mu, gamma)`/fixed-gain parameterizations are archived.
- Public constructors no longer expose alpha initialization or obsolete
  parameterization switches; the dimensionless internal reference is one.
- The adaptive implementation uses the smaller exact system: rank-space
  Woodbury for the maintained fast path and a portable primal solve when valid
  tokens are fewer than rank.
- ImageNet and sequence metrics accumulate on-device and transfer scalar
  diagnostics in batches, avoiding per-minibatch host synchronization.

## Training and notebook

- The formal DeiT-III notebook installs the matching ABI 2 runtime wheel,
  checks the official recipe, runs a target-GPU save/resume gate, launches a
  detached trainer, monitors it independently, and creates validated archives.
- RRLSSO-specific gain-anchor and alpha-saturation losses are removed. The
  general initialization-versus-resume state machine remains so refinement
  cannot overwrite stage-local EMA, optimizer, scheduler, scaler, or RNG state.
- Hugging Face cache completion logs are reduced to start, quartile milestones,
  and completion while retaining per-shard failure diagnostics.

- The CUDA 12.8 wheel passed the complete repository suite: 254 tests.
- Both installed wheels independently passed the 83 native Trace/backend
  numerical, gradient, and mask-safety tests.

  installation rather than the development build directory.
- Runtime dependencies resolve to the matching CUDA runtime major version.
